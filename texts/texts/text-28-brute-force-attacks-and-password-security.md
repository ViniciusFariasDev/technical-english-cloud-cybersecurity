# Text 28 – Technical English – Brute Force Attacks and Password Security

## 📄 Text

A brute force attack  
is a technique used by attackers  
to guess passwords  
by trying many combinations  
until the correct one is found.

Attackers use automated tools  
to test thousands  
or millions of passwords  
in a short time.  
Weak passwords  
make this attack easier.

Brute force attacks  
target login systems,  
user accounts,  
and remote access services.  
If successful,  
attackers gain unauthorized access  
to systems and data.

Organizations use strong passwords,  
multi-factor authentication,  
and account lockout policies  
to prevent brute force attacks.

Proper password security  
reduces the risk of unauthorized access  
and protects sensitive information.

---

## 📚 Vocabulary

- **Brute force attack** – ataque de força bruta  
- **Guess passwords** – adivinhar senhas  
- **Automated tools** – ferramentas automatizadas  
- **Weak passwords** – senhas fracas  
- **Login systems** – sistemas de login  
- **Unauthorized access** – acesso não autorizado  
- **Account lockout** – bloqueio de conta
